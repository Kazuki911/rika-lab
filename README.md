# りかラボ

中学理科の学習に使う、10種類のインタラクティブ教材。HTML / CSS / JavaScriptのみで動作し、ビルドやAPIキーは不要です。

## 教材

| 教材 | 主な操作・観察 |
| --- | --- |
| 振り子のリズム | 長さ・振れ幅・質量、周期と振れ角の波形 |
| ばねと力の関係 | 質量・ばね定数・重力、伸びと比例グラフ |
| 電流の通り道 | 直列・並列、電圧・2つの抵抗、枝分かれした電流 |
| 凸レンズの向こう側 | 焦点距離・物体距離・高さ、実像・虚像と光線 |
| 音を、目で見よう | 振動数・振幅・音速、時間波形と縦波の模式図 |
| 水の中では、軽くなる？ | 深さ・体積・液体密度、水圧と浮力 |
| 粒子で見る、気体の世界 | 温度・容積・粒子量、粒子運動と相対圧力 |
| 葉っぱの小さな工場 | 光・CO₂・水温、光合成と呼吸・酸素の泡 |
| 雲が生まれる境界線 | 温度・水の総量、湿度・露点・凝結量 |
| 月のかたちと位置 | 月齢・自動公転、宇宙視点と地球からの見え方 |

各教材に条件操作、観察値、一時停止、1コマ送り、再生速度、リセット、解説、ミニ実験、考察のヒントがあります。ばねなど静的なモデルでは、時間を進めても図は変化しません。

## 開き方

`index.html` をブラウザで開いて利用できます。保存機能を含めて確認する場合は、このフォルダーで次を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000` を開きます。教材には `#lab/moon` などのURLで直接アクセスできます。

## GitHub Pagesで公開

1. GitHubにリポジトリを作り、このフォルダーの `index.html`、`assets/`、`.nojekyll` をリポジトリのルートに追加してpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、ファイルを置いたブランチと **/ (root)** を指定して保存します。
4. デプロイ完了後、Pagesに表示された公開URLを開きます。

すべてのアセット参照は相対パスなので、`https://ユーザー名.github.io/リポジトリ名/` の形式にも対応します。サーバー側の処理やビルド設定は不要です。

公開先： https://kazuki911.github.io/rika-lab/

リポジトリ： https://github.com/Kazuki911/rika-lab

## 記録とモデルについて

- 実験記録は教材ごとに最大100件、ブラウザのlocalStorageに保存します。
- 記録には条件と観察値を保存し、CSV（UTF-8 BOM付き）でダウンロードできます。
- 同一端末でもブラウザや公開元URLが変わると記録は共有されません。プライベートブラウズ・保存制限・データ消去などで記録が失われる可能性があるため、必要な記録はCSVで保存してください。
- 保存できない場合は現在の画面内に記録を保持し、通知を表示します。
- 学習向けの理想化モデルです。適用範囲や省略条件を各教材の解説に記載しています。光合成は実測値ではない定性モデル、気体の圧力は発展内容を含む相対モデルです。
- 外部画像・JavaScriptライブラリは使用していません。Google Fontsから日本語フォントを読み込みますが、読み込めない場合は端末標準フォントで動作します。実験記録は外部送信しません。
- タッチ操作・キーボードによる入力、狭い画面の縦並びレイアウトに対応しています。キャンバスの主要な観察値はHTMLテキストでも表示します。

## 検証

Node.jsがある環境で次を実行できます。

```sh
node --check assets/app.js
node tests/verify.cjs
```

物理モデルの関係を15項目、全10教材について初期値・上下限など86通りのCanvas描画を検証します。ブラウザでは別途、10教材の表示・実行エラー、検索、分野フィルター、記録と再読み込み、PC・モバイルの表示を確認しています。

## ファイル構成

- `index.html` — ホームと共通の実験画面
- `assets/style.css` — デザイン、レスポンシブ対応
- `assets/app.js` — 教材データ、計算、Canvas描画、記録
- `tests/verify.cjs` — 依存パッケージ不要のモデル・描画テスト
- `.nojekyll` — GitHub Pages用

教材を追加するときは `assets/app.js` の `lessons`、`icons`、`values`、`drawers` に教材の定義を追加します。
